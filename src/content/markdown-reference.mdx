## Code

Inline `const x = 1` sits in the flow of a sentence. Fenced blocks get their own
treatment with a copy button on hover:

```ts
interface Doc {
  slug: string
  title: string
  Component: ComponentType
}

export function getDoc(slug: string): Doc | undefined {
  return docs.find((doc) => doc.slug === slug)
}
```
